**The port is a solo project.** tsatria03 is its only author. There are no code contributors.

**One credit beside the dev's: theblindgamer50,** who helped tsatria03 recover all of the episodes from version 1.3.2 of the original, the version the port plays (the dev, 2026-10-18: "add theblindgamer50 to the credits as well. He's the one who helped me recover all of the episodes from 1.3.2 version of the game"). They are credited for that recovery, not as an author of the port. The 1.3.2 app shipped with only the Prologue; the other episodes came from Reactive Studios' server, since taken down, and theblindgamer50 had downloaded them all beforehand and dumped them out (the dev, 2026-10-18; [[project_original_status]]). How is their own business: never ask, guess or record it. **theblindgamer50 has no GitHub account** (the dev, 2026-10-18), so the name is written as the dev gave it, never linked to GitHub, and never mentioned in a commit as a GitHub user; it is the one exception to naming people by GitHub username ([[feedback_use_github_usernames]]).

**Why:** The dev said so on 2026-10-17: "Recall that this is strictly a solo project. No contributors. I'll let you know if that ever changes." The credit for theblindgamer50 was added by the dev on 2026-10-18.

**How to apply:**
- Commits have tsatria03 as author, with no `Co-authored-by:` line for any person. Only the Claude attribution line is added ([[feedback_git_commits]]).
- The credits, in the game, the README and the player readme, name tsatria03 for the port, theblindgamer50 for recovering the 1.3.2 episodes, and Reactive Studios for the original game.
- Never credit, mention or assume any other contributor in notes, docs, comments or the changelog.
- If the dev ever says someone has joined, update this note first.
